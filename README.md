# 实时电音变声器

一个纯前端 Web Audio 网站，可以上传音频做电音处理，也可以打开麦克风实时监听、录制并导出 WAV。

## 使用方式

直接部署 `index.html`、`styles.css`、`app.js` 到 GitHub Pages、Netlify、Vercel 或任意静态网站服务即可。

## 麦克风权限

浏览器必须允许当前网站使用麦克风。首次点击“刷新麦克风”“只开实时传声”或“边唱边录电音”时，浏览器会弹出授权窗口，请选择允许。

如果没有弹窗，检查浏览器设置里的麦克风权限，并确认 Windows 的“允许桌面应用访问麦克风”已开启。

## 注意

实时传声建议戴耳机，避免扬声器声音回到麦克风形成啸叫。
