# ⚡ 实时电音变声器 · Electro Voice

一个纯前端 Web Audio 网站，可以上传音频做电音处理，也可以打开麦克风实时监听、录制并导出 WAV。

## 🎤 5 种电音模式

| 模式 | 效果 | 波形 |
|------|------|------|
| 🎤 **经典电音** | 音阶量化修音，自动修正到最近音高 | 正弦波 + 泛音 |
| 🤖 **机器人** | 方波重新合成人声，机械感 | 软方波 + 谐波 |
| 👽 **外星人** | 共振峰偏移，非人类声线 | 正弦波 + 3次泛音 |
| 🌌 **空灵** | 电音修音 + 双声部合唱 + 混响 | 正弦波 + 失谐第二声部 |
| 💥 **电子核** | 暴力电音 + 失真 + 比特压缩 | 软方波 + 失真 |

## 🚀 核心特性

- **AudioWorklet 实时音高检测** — 自相关算法 + 抛物线插值，精确检测人声基频
- **音阶量化修音** — 支持小调、大调、五声音阶、半音阶
- **5 种合成模式** — 每种模式独立的波形合成算法
- **失真 + 比特压缩** — 为电子核/机器人模式增加力度
- **共振峰偏移** — 外星人模式专用
- **实时音高显示** — 当前唱的音名和频率实时展示
- **频谱/波形双视图** — 按 `V` 键切换
- **键盘快捷键** — Space 启停、R 录制、1-5 切换预设、V 切换视图
- **用户预设系统** — 保存/加载/删除自定义效果设置（localStorage）
- **文件上传处理** — 上传音频文件并导出电音版 WAV
- **实时录制** — 边唱边录，导出 WAV

## 使用方式

### 部署

**不要直接用 `file://` 打开 `index.html`** — 浏览器会阻止麦克风功能。

推荐方式（三选一）：

```bash
# 方式 1: npx serve（推荐）
npx serve .

# 方式 2: Python
python -m http.server 8501

# 方式 3: GitHub Pages
# 推送到 GitHub 后开启 Pages 即可（自动 HTTPS）
```

打开后浏览器会显示 `http://localhost:3000`（或类似地址），**必须通过 `localhost` 或 `HTTPS` 才能使用麦克风**。

### 快捷键

| 键 | 功能 |
|----|------|
| `Space` | 启动/停止实时传声 |
| `R` | 开始/停止录制 |
| `S` | 停止传声 |
| `1`-`5` | 快速切换预设 |
| `V` | 切换频谱/波形视图 |

## 浏览器兼容性

| 浏览器 | 状态 |
|--------|------|
| Chrome 86+ | ✅ 完全支持 |
| Edge 86+ | ✅ 完全支持 |
| Firefox | ⚠️ AudioWorklet 支持有限 |
| Safari | ⚠️ 可能有限制的 AudioWorklet 行为 |

推荐使用 Chrome 或 Edge。

## 麦克风权限

浏览器必须允许当前网站使用麦克风。首次点击"实时传声"时，浏览器会弹出授权窗口，请选择允许。

如果权限被拒绝，请在浏览器地址栏的权限设置中重新开启麦克风权限。

## 注意

实时传声建议戴耳机，避免扬声器声音回到麦克风形成啸叫。
